# ProofGraph AI
### From Documents to Decisions, Powered by Proof.

**ProofGraph AI** is an AI-powered application validation and regulatory compliance platform designed to streamline institutional document verification, identify compliance discrepancies, and improve evidence traceability through an integrated review workflow.

The platform combines document analysis, configurable rule-based validation, evidence-linked findings, and human-in-the-loop review to make compliance processes more structured, transparent, and accountable.

---

## Overview

Traditional application verification often involves repetitive manual checks, fragmented records, and difficulty tracking discrepancies across multiple documents.

ProofGraph AI addresses these challenges through a centralized platform that processes submitted documents, extracts relevant information, evaluates configurable validation rules, and presents findings in an organized dashboard.

Rather than treating every automated result as a final decision, the system allows human reviewers to investigate uncertain findings and maintain oversight of critical verification decisions.

## Key Features

- **Document Analysis:** Extracts relevant information and fields from submitted documents.
- **Application Validation:** Evaluates extracted information against configurable compliance rules.
- **Evidence-Linked Findings:** Connects detected discrepancies with document names, page references, and supporting information.
- **Status Classification:** Categorizes validation results into PASS, MISMATCH, UNVERIFIED, and MANUAL REVIEW.
- **Human-in-the-Loop Review:** Allows reviewers to investigate findings, add notes, and update review statuses.
- **Centralized Dashboard:** Displays application statistics, processed documents, flagged findings, and pending reviews.
- **Configurable Rules:** Supports adjustable validation rules and expiry-warning settings.
- **Application Management:** Provides a structured view of submitted applications and their associated documents.

## Validation Categories

| Status | Description |
|---|---|
| PASS | Validation rule satisfied |
| MISMATCH | Detected information does not match the expected value |
| UNVERIFIED | Available information is insufficient for verification |
| MANUAL REVIEW | Requires additional human examination |
